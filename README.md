**網址：** https://s11428127.github.io/Singapore/

|---|---|
| `index.html` | 行程主頁（進站第一頁），列出所有行程、顯示出發倒數 |

## 技術說明

- 每頁都是單一 HTML（CSS／JS 內嵌），沒有外部相依，離線也能看
- 行程動線圖是手繪的 inline SVG，不依賴外部圖床
- 行前清單的勾選狀態存在瀏覽器 localStorage，每個行程各自獨立，只留在勾選的那台裝置上

## 之後想改內容

在 GitHub 網頁上點對應的 `.html` → 右上角鉛筆圖示編輯 → 修改 → Commit，Pages 會自動重新部署。

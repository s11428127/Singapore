## 匯出 PDF

每個行程頁面右下角有「存成 PDF」按鈕，可勾選要匯出的章節（預設全選），
再透過瀏覽器的列印功能存成 PDF。兩趟行程各自獨立匯出。

- iPhone：跳出分享視窗 → 列印 → 預覽圖兩指放大 → 分享 → 儲存到檔案
- Android：印表機選「儲存為 PDF」
- 電腦：目的地選「另存為 PDF」

匯出時會自動展開所有摺疊的說明區塊、隱藏分頁列與按鈕，並讓每個章節獨立分頁。
出國沒網路時可以先存起來離線看。

## 技術說明

- 每頁都是單一 HTML（CSS／JS 內嵌），沒有外部相依，離線也能看
- 行程動線圖是手繪的 inline SVG，不依賴外部圖床
- 行前清單的勾選狀態存在瀏覽器 localStorage，每個行程各自獨立，只留在勾選的那台裝置上
